# Menu inferior flutuante — RCarPremium

Foi atualizado o componente compartilhado `bottom_nav.xml`, utilizado pelas telas que incluem o menu inferior. O menu agora tem fundo preto translúcido, borda laranja, cantos arredondados, elevação e margens laterais/inferiores para criar o efeito flutuante. A navegação e os IDs existentes foram preservados.

Abra a pasta `work_rcar` no Android Studio, sincronize o Gradle e execute **Build > Make Project** para validar no seu ambiente.
