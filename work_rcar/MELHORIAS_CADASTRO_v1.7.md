# RCarPremium v1.7 — Tela de cadastro

## Melhorias
- Interface de cadastro redesenhada com o tema preto e laranja da RCAR Premium.
- Logo com proporção adequada, título e texto de apoio mais claros.
- Formulário agrupado em painel escuro com bordas arredondadas.
- Rótulos explícitos para nome, e-mail e senha.
- Campos escuros com borda laranja quando recebem foco.
- Botão de cadastro destacado e link de retorno ao login com cor de acento.
- Layout rolável para telas menores e tratamento das áreas seguras do sistema.
- Validação adicional de formato do e-mail; regras existentes de nome e tamanho mínimo de senha continuam preservadas.

## Observação
A tela de login existente não foi redesenhada. As alterações visuais se concentram na tela de cadastro de cliente.
